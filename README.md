# Opportunity Radar Agent

An AI Agent built on Fetch.ai Agentverse and deployed on ASI:One for Fetch-A-Thon 3.0.

## Overview
Opportunity Radar helps students discover scholarships, internships, hackathons, and open-source opportunities. It checks eligibility, verifies deadlines, and provides structured action checklists.

## How to Test
1. Open ASI:One.
2. Search for `@opportunity-radar`.
3. Ask for eligibility or prep roadmap for hackathons/scholarships.
